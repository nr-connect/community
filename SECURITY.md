# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues or discussions.**

Instead, report them privately using either of these channels:

1. **Email:** `support@nr-connect.com` (subject: `[SECURITY] ...`)
2. **Portal Support Form:** Sign in at https://nr-connect.com/support and choose the **Security issue** category.

Please include:
- A clear description of the vulnerability and potential impact
- Steps to reproduce or a minimal proof of concept
- Any affected versions (`@nr-connect/node-red` version, connector version, or portal route)

We will acknowledge receipt promptly and coordinate a fix and disclosure timeline with you.
